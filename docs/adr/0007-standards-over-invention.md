# ADR-007: Use AGENTS.md, SKILL.md and MCP as they are

- **Status:** Accepted
- **Date:** 2026-11-16
- **Source:** Building Harness, Part 5.2

## Context

Other tools already define these formats and have ecosystems around them.

## Decision

Read the standard formats and locations, including `.claude/skills` for compatibility.

## Consequences

Existing skills and MCP servers work on day one.
