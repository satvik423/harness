# ADR-018: Licence: MIT OR Apache-2.0

- **Status:** Accepted
- **Date:** 2026-11-17
- **Source:** Phase 0 review, approved by the user

## Context

The manifests declared `MIT OR Apache-2.0` (from the plan's example) but no licence files existed and the owner had not chosen.

## Decision

The project is dual-licensed under MIT or Apache-2.0, at the user's option, the standard choice for Rust projects. `LICENSE-MIT` and `LICENSE-APACHE` are in the repository root.

## Consequences

Anyone may use, modify and redistribute the code, including commercially, while keeping the copyright notice; Apache-2.0 adds a patent grant. Contributions are accepted under the same terms.
