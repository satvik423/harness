# harness documentation

harness is a general-purpose, persona-driven agent harness written in Rust.
The full product plan (PRD, design, technical spec, phase plan, guardrails) is
[`building-harness.html`](../building-harness.html) in the repository root.

| Folder | What is in it |
|---|---|
| [architecture/](architecture/overview.md) | How the crates fit together and which dependency directions are allowed |
| [crates/](crates/) | One page per crate: purpose, public API, examples, design notes |
| [adr/](adr/README.md) | Architecture decision records |
| [guides/](guides/) | User guides, added as features land ([configuration](guides/configuration.md)) |
| [phases/](phases/) | One report per completed phase |

## Building and checking

```sh
cargo build
cargo nextest run --workspace --all-features
cargo test --workspace --doc
cargo clippy --workspace --all-targets --all-features -- -D warnings
RUSTDOCFLAGS="-D warnings" cargo doc --workspace --no-deps --open
cargo deny check
cargo llvm-cov --workspace --summary-only
```

API documentation for every crate is generated by `cargo doc` from the
inline rustdoc comments.
